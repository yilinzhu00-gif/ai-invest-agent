# P2-04 CrewAI 双 Agent Flow

> 状态：执行中。此包保持 `langgraph` 默认回退，不调用外部模型，也不改变工具权限。

## 目标与边界

将一次研究请求约束为 `请求 -> Analyst 草稿 -> Python 硬校验 -> Reviewer 决策 -> 最多一次定向修订 -> 人工审核`。Agent 只能处理已传入的证据和草稿，不能改变 workspace、原始数据或权限；任何 schema、数值、引用、权限校验失败都在进入 Reviewer 前终止。

## 实施顺序

1. 先写确定性假 Agent 的测试，覆盖硬校验、一次修订上限和运行时开关。
2. 锁定 CrewAI，并用独立 adapter 将其隔离在 `crewai` runtime 路径；测试不需网络或 API Key。
3. 新增结构化 state、草稿、审核决策和 Python validator；将 `allow_delegation=False` 固定在两个角色配置中。
4. 增加基准 JSONL 和 CLI，对同一数据集输出两种 runtime 的门禁、延迟、工具次数与成本汇总。
5. 将开发执行器接到 runtime 开关；仍保留原 LangGraph 路径作为迁移回退。
